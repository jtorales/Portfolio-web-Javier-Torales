PORTFOLIO WEB — JAVIER MAXIMILIANO TORALES

Contenido:
- index.html: página web principal.
- assets/: las 10 capturas originales de Cisco Packet Tracer.

Cómo probar:
1. Descomprimir el ZIP.
2. Abrir index.html en un navegador.

Cómo publicar:
- Subir index.html y la carpeta assets completa al directorio público del hosting
  (por ejemplo, public_html o www).
- Mantener la estructura de carpetas para que carguen las imágenes.
- No hace falta base de datos ni backend: es un sitio estático.

La página incluye selector Español / English, navegación por secciones,
enlaces de contacto y LinkedIn, y diseño responsive.
